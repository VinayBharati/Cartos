# 🛒 Cartos: E-Commerce with Augmented Reality (AR)  

**Cartos** is a next-gen mobile e-commerce platform built using the **MERN** stack and **React Native**, delivering an immersive shopping experience through **Augmented Reality (AR)** integration. Designed to be scalable and feature-rich, it offers a reliable solution for businesses and developers aiming for modern e-commerce.  

---

## 🔥 Key Features  
- **⚛️ Redux Saga for Smooth State Management** – Ensures seamless handling of asynchronous operations and optimal app performance.  
- **🔎 AR Product Viewer** – Visualize products in real-time within the customer's environment, offering an immersive shopping experience.  
- **💳 Razorpay Payment Integration** – Secure and smooth transactions with Razorpay (requires individual API key generation).  
- **📈 Scalable Architecture** – Built to handle growth, with a robust backend and optimized frontend for increased traffic and inventory management.  
- **🎨 Atomic Design Pattern** – Utilizes modular and reusable components for efficient development and future scalability.  
- **📊 Dynamic Business Dashboard** – Real-time tracking of orders, inventory, and customer data for streamlined business operations.  
- **🔐 Razorpay Key Generation** – Each user must generate their own Razorpay keys for secure payment gateway integration.  

---

## 🛠 Tech Stack  
- **React Native (Expo)** – Mobile app development  
- **MERN Stack** – MongoDB, Express, React, Node.js  
- **Redux Saga** – State management  
- **Razorpay** – Payment gateway integration  
- **Augmented Reality (AR)** – Real-time product visualization
